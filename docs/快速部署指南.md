# Passkey 项目 - 快速部署指南

## 🚀 一键部署(推荐)

### 第一步: 自动配置

```powershell
python setup.py
```

这个脚本会自动:
- ✅ 检测本机hostname
- ✅ 生成SSL自签名证书
- ✅ 配置Windows防火墙规则
- ✅ 创建配置文件
- ✅ 检查并安装依赖

### 第二步: 启动服务器

**方法1 (推荐):**
双击 `start.ps1` 文件

**方法2:**
```powershell
python server_dynamic.py
```

### 第三步: 在手机上访问

1. 确保手机和电脑在同一WiFi网络
2. 在手机浏览器中访问: `https://你的电脑名.local:5000`
3. 接受自签名证书警告
4. 开始使用!

---

## 📋 手动部署

如果自动配置失败,可以手动操作:

### 1. 安装依赖

```powershell
pip install -r requirements.txt
```

### 2. 生成SSL证书

```powershell
python generate_cert.py
```

### 3. 配置防火墙(需要管理员权限)

```powershell
New-NetFirewallRule -DisplayName "Passkey Test Server" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow
```

### 4. 创建配置文件

创建 `config.py` 文件:

```python
import socket

HOSTNAME = socket.gethostname()
RP_ID = f"{HOSTNAME}.local"
RP_NAME = "Passkey 测试"
PORT = 5000
```

### 5. 启动服务器

```powershell
python server_dynamic.py
```

## 📱 手机访问说明

### iOS (iPhone/iPad)

1. 确保设备和电脑在同一WiFi
2. 打开Safari浏览器
3. 访问: `https://电脑名.local:5000`
4. 点击"高级" → "继续访问此网站"
5. 使用Face ID或Touch ID进行Passkey操作

### Android

1. 确保设备和电脑在同一WiFi
2. 打开Chrome浏览器
3. 访问: `https://电脑名.local:5000`
4. 点击"高级" → "继续访问此网站(不安全)"
5. 使用指纹或面部识别进行Passkey操作

### 如果.local域名无法访问

使用IP地址访问: `https://你的IP:5000`

查看本机IP:
```powershell
ipconfig | findstr IPv4
```

## ❓ 常见问题

### Q1: 手机无法访问服务器

**检查清单:**
- ✅ 手机和电脑在同一WiFi网络
- ✅ Windows防火墙已配置
- ✅ 服务器正在运行
- ✅ 使用HTTPS协议(不是HTTP)

**解决方案:**
```powershell
# 检查防火墙规则
Get-NetFirewallRule -DisplayName "Passkey Test Server"

# 如果没有,手动添加
New-NetFirewallRule -DisplayName "Passkey Test Server" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow
```

### Q2: mDNS(.local)域名无法解析

**iOS/macOS:** 默认支持mDNS,应该可以正常访问

**Android/Windows:** 可能不支持mDNS

**解决方案:** 使用IP地址代替:
```
https://192.168.1.xxx:5000
```

### Q3: 证书错误

这是正常的!因为使用的是自签名证书。

**解决方案:** 在浏览器中接受证书:
- iOS Safari: 点击"继续访问此网站"
- Android Chrome: 点击"高级" → "继续"

### Q4: WebAuthn错误 "NotAllowedError"

**可能原因:**
- 没有使用HTTPS
- RP ID配置错误
- 浏览器不支持WebAuthn

**解决方案:**
1. 确认使用HTTPS协议
2. 检查配置文件中的RP_ID
3. 使用较新版本的浏览器

## 🔐 安全说明

⚠️ **这是测试项目,不要用于生产环境!**

存在的安全问题:
- 使用自签名证书(生产环境需要CA签发的证书)
- 数据存储在内存中(重启后丢失)
- 没有用户认证和授权
- 没有速率限制

如需生产部署,请:
1. 使用有效的SSL证书(Let's Encrypt等)
2. 使用数据库存储用户数据
3. 添加用户会话管理
4. 实施速率限制和安全防护
5. 进行安全审计
