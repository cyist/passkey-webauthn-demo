```
│  │  路由处理    │ ◄────► │  py_webauthn 库              │   │

│  ┌──────────────┐         ┌─────────────────────────────┐   │
```

### 组件说明

#### 前端 (`index_dynamic.html` + `passkey.js`)

- **职责**: 
  - 用户界面展示
  - WebAuthn API 调用
  - 数据格式转换（Base64URL ↔ ArrayBuffer）
  
- **关键技术**:
  - `navigator.credentials.create()` - 注册 Passkey
  - `navigator.credentials.get()` - 认证 Passkey
  - 动态加载配置 (`/config.js`)

#### 后端 (`server_dynamic.py`)

- **职责**:
  - 生成 WebAuthn 挑战
  - 验证注册/认证响应
  - 存储凭证信息
  - 动态配置管理

- **关键库**:
  - `Flask` - Web 框架
  - `webauthn` - WebAuthn 服务器端实现
  - `cryptography` - SSL 证书生成

#### 配置系统 (`setup.py`)

- **职责**:
  - 自动检测环境
  - 生成 SSL 证书
  - 配置防火墙
  - 创建配置文件

## 🔐 WebAuthn 流程

### 注册流程

```
客户端                                            服务器
  │                                                 │
  │  1. POST /register/begin                       │
  │     { username: "alice" }                      │
  ├────────────────────────────────────────────────►│
  │                                                 │ 生成 challenge
  │                                                 │ 生成 user_id
  │  2. registration options                       │
  │     { challenge, user, rp, ... }               │
  │◄────────────────────────────────────────────────┤
  │                                                 │
  │  3. navigator.credentials.create()             │
  │     → 用户生物识别认证                          │
  │     → 生成密钥对                                │
  │     → 创建 attestation                          │
  │                                                 │
  │  4. POST /register/complete                    │
  │     { credential: {...} }                      │
  ├────────────────────────────────────────────────►│
  │                                                 │ 验证 challenge
  │                                                 │ 验证 origin
  │                                                 │ 提取公钥
  │  5. { verified: true }                         │ 存储凭证
  │◄────────────────────────────────────────────────┤
  │                                                 │
```

### 认证流程

```
客户端                                            服务器
  │                                                 │
  │  1. POST /login/begin                          │
  │     { username: "alice" }                      │
  ├────────────────────────────────────────────────►│
  │                                                 │ 生成 challenge
  │                                                 │ 查找用户凭证
  │  2. authentication options                     │
  │     { challenge, allowCredentials, ... }       │
  │◄────────────────────────────────────────────────┤
  │                                                 │
  │  3. navigator.credentials.get()                │
  │     → 用户生物识别认证                          │
  │     → 使用私钥签名                              │
  │     → 创建 assertion                            │
  │                                                 │
  │  4. POST /login/complete                       │
  │     { credential: {...} }                      │
  ├────────────────────────────────────────────────►│
  │                                                 │ 验证 challenge
  │                                                 │ 验证签名
  │  5. { verified: true }                         │ 更新计数器
  │◄────────────────────────────────────────────────┤
  │                                                 │
```

## 🔑 密钥管理

### 密钥生成

1. **客户端生成密钥对**
   - 使用设备安全元件（Secure Enclave、TEE）
   - 私钥永不离开设备
   - 公钥发送给服务器

2. **密钥算法**
   ```python
   # 支持的算法
   COSEAlgorithmIdentifier.ECDSA_SHA_256  # -7 (推荐)
   COSEAlgorithmIdentifier.RSASSA_PKCS1_v1_5_SHA_256  # -257
   ```

### 凭证存储

```python
# 服务器存储结构
users_db = {
    "alice": {
        "id": b'\x12\x34\x56...',  # 用户 ID (32 bytes)

            {
                "credential_id": b'\xab\xcd\xef...',  # 凭证 ID
                "public_key": b'\x04\x...',           # 公钥

                "credential_type": "public-key",
                "credential_device_type": "platform",
                "credential_backed_up": False

    }
```

## 🌐 网络配置

### mDNS 原理

**Multicast DNS (mDNS)** 允许在局域网内使用 `.local` 域名:

1. **工作原理**:
   - 设备广播自己的 hostname
   - 其他设备通过组播发现
   - 无需 DNS 服务器

2. **Windows 支持**:
   - Windows 10+ 部分支持
   - 可能需要 Bonjour 服务

3. **域名格式**:
   ```
   hostname.local  # 必须小写
   ```

### SSL/TLS

**自签名证书生成**:

```python
# 使用 cryptography 库
cert = x509.CertificateBuilder().subject_name(
    ...
).add_extension(
    x509.SubjectAlternativeName([
        x509.DNSName("hostname.local"),  # mDNS 域名
        x509.IPAddress("192.168.1.x"),   # IP 地址
    ]),
    critical=False,
)
```

**证书字段**:
- **Subject**: CN=hostname.local
- **SAN**: DNS:hostname.local, IP:192.168.1.x
- **有效期**: 365 天

## 📊 数据格式

### Base64URL 编码

WebAuthn 使用 Base64URL 编码（非标准 Base64）:

```javascript
// JavaScript 转换
function bufferToBase64url(buffer) {
    const base64 = btoa(String.fromCharCode(...new Uint8Array(buffer)));
    return base64
        .replace(/\+/g, '-')
        .replace(/\//g, '_')
        .replace(/=/g, '');
}

function base64urlToBuffer(base64url) {
    const base64 = base64url
        .replace(/-/g, '+')
        .replace(/_/g, '/');
    const binary = atob(base64);
    return Uint8Array.from(binary, c => c.charCodeAt(0)).buffer;
}
```

```python
# Python 转换
def base64url_to_bytes(data: str) -> bytes:
    padding = 4 - (len(data) % 4)
    if padding != 4:
        data += '=' * padding
    data = data.replace('-', '+').replace('_', '/')
    return base64.b64decode(data)
```

### WebAuthn 对象结构

**注册凭证**:
```javascript
{
    id: "base64url_encoded_credential_id",
    rawId: ArrayBuffer,
    type: "public-key",
    response: {
        clientDataJSON: ArrayBuffer,
        attestationObject: ArrayBuffer
    }
}
```

**认证凭证**:
```javascript
{
    id: "base64url_encoded_credential_id",
    rawId: ArrayBuffer,
    type: "public-key",
    response: {
        clientDataJSON: ArrayBuffer,
        authenticatorData: ArrayBuffer,
        signature: ArrayBuffer,
        userHandle: ArrayBuffer
    }
}
```

## 🔒 安全考虑

### 挑战 (Challenge)

- **目的**: 防止重放攻击
- **要求**: 
  - 随机生成（至少 16 bytes）
  - 一次性使用
  - 服务器端验证

```python
# 生成 challenge
challenge = secrets.token_bytes(32)

# 存储（临时）
challenges_db[username] = challenge

# 验证后删除
del challenges_db[username]
```

### Origin 验证

```python
# 服务器验证
expected_origin = f"https://{RP_ID}:{PORT}"
actual_origin = client_data.origin

if actual_origin != expected_origin:
    raise Exception("Origin mismatch")
```

### RP ID 规则

- **必须是有效域名** - 不能是 IP 地址
- **必须匹配访问域名** - 包括大小写
- **可以是子域** - `auth.example.com` 的 RP ID 可以是 `example.com`

### 签名计数

```python
# 防止凭证克隆
if new_sign_count <= stored_sign_count:
    # 可能的克隆攻击
    raise Exception("Invalid sign count")

# 更新计数
credential['sign_count'] = new_sign_count
```
